REST API Specification

The Flask backend exposes three main inference endpoints accepting both multipart file uploads and raw coordinates for Planetary Computer integration.

POST /predict_location

Fetches live Sentinel-2 multispectral imagery from Microsoft Planetary Computer STAC API for the given coordinates and runs neural inference.

curl -X POST http://localhost:5000/predict_location \ -H "Content-Type: application/json" \ -d '{"lat": 30.56, "lon": 32.28, "days_back": 120, "cloud_max": 30}'

POST /predict

Accepts a multipart file upload (.tif/.tiff), performs model inference, and directly streams back the binary water mask as a PNG image.

curl -X POST http://localhost:5000/predict \ -F "file=@test_samples/sample_high_water.tif" \ --output water_mask.png

POST /predict_json

Accepts a multipart file upload and returns detailed JSON metrics along with Base64-encoded binary mask and RGB false-color overlay.

curl -X POST http://localhost:5000/predict_json \ -F "file=@test_samples/sample_high_water.tif"
